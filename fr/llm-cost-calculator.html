Questions fréquentes

Quel est le coût de GPT-5.4 nano par million de tokens ?+

GPT-5.4 nano coûte $0,20 par million de tokens d'entrée et $1,25 par million de tokens de sortie (juin 2026). C'est 25× moins cher que GPT-5.5.

Quelle est l'API LLM la moins chère en 2026 ?+

GPT-5.4 nano ($0,20/$1,25 par 1M) et Gemini 3.1 Flash-Lite ($0,25/$1,50 par 1M) sont les options les plus abordables.

Quel est le coût de Claude Sonnet 4.6 ?+

Claude Sonnet 4.6 coûte $3,00 par million de tokens d'entrée et $15,00 par million de tokens de sortie via l'API Anthropic.

Comment réduire les coûts API LLM ?+

Utilisez des modèles moins chers, activez le Batch API pour -50% sur les tâches asynchrones, mettez les prompts en cache et définissez max_tokens.
