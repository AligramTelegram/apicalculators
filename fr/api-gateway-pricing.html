Questions fréquentes

Quel est le coût d'AWS API Gateway pour 10 millions de requêtes ?+

AWS REST : $35/mois. HTTP API : $10/mois. Cloudflare API Shield : $5/mois. Kong auto-hébergé : seulement le coût serveur.

Cloudflare vs AWS API Gateway — lequel est moins cher ?+

Cloudflare ($0,50/1M) est 7× moins cher qu'AWS REST API ($3,50/1M) et inclut cache edge et protection DDoS.

Oui, au-delà de 5M requêtes/mois. Serveur Hetzner (€4,35/mois) + Kong = bien moins cher que les gateways managées. Avantage RGPD avec stockage EU.
