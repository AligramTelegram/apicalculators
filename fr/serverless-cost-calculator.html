💡 Prix Cloudflare Workers en détail

Le plan Free inclut 100 000 req/jour (≈3M/mois) + 10ms CPU par requête. Le plan Workers Paid à $5/mois monte à 10M req/mois puis $0,30/1M supplémentaire, avec 30ms CPU et Workers KV inclus. Pour les équipes EU, Cloudflare exécute le code sur le PoP le plus proche — Paris, Frankfurt, Amsterdam — avec une latence de démarrage quasi nulle (cold start <5ms vs 50–200ms pour Lambda).

Questions fréquentes

Quel est le coût d'AWS Lambda pour 1 million d'invocations ?+

$0,20 de frais de requêtes + compute. 256MB, 150ms : ~$0,84/mois. Premier 1M invocations + 400K GB-s gratuits.

Quelle est la limite gratuite de Vercel Functions ?+

100 000 invocations/mois gratuites sur le plan Hobby. Ensuite $0,40 par 1M sur le plan Pro.

Cloudflare Workers est-il meilleur qu'AWS Lambda pour les utilisateurs européens ?+

Oui. Cloudflare Workers tourne sur le réseau edge incluant Paris — latence typique <10ms pour les utilisateurs EU. AWS Lambda (eu-west-3 Paris) a ~20–50ms de cold start.

Quel est le prix de Cloudflare Workers en 2026 ?+

Plan Free : 100 000 requêtes/jour gratuites (≈3M/mois), 10ms CPU par requête, aucune carte bancaire requise. Plan Workers Paid : $5/mois fixe, inclut 10M requêtes/mois et 30ms CPU/requête, puis $0,30 par million de requêtes supplémentaires. Comparé à AWS Lambda ($0,20/1M + compute) ou Vercel ($0,40/1M), Cloudflare Workers est la solution la moins chère pour les workloads à fort volume en Europe, grâce à l'absence de cold start et au tier gratuit le plus généreux du marché.
