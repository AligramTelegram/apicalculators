FAQ

Combien coute AWS Lambda par million de requetes?+

Apres le tier gratuit (1M/mois), Lambda coute $0.20 par million d'invocations plus les couts de calcul. Une fonction 256MB a 200ms = ~$3.47/mois pour 10M invocations.

Cloudflare Workers est-il moins cher que Lambda?+

Pour les courtes durees (moins de 30ms) a haute frequence oui. Workers a $0.30/M bat Lambda. Pour les calculs plus longs ou les integrations AWS, Lambda est souvent meilleur.
