Questions fréquentes

Quel est le coût de l'API OpenAI Whisper par heure d'audio ?+

Whisper : $0,006/minute = $0,36/heure. 10 000 minutes/mois = $60/mois.

ElevenLabs vaut-il le prix pour la synthèse vocale en français ?+

ElevenLabs ($330/1M caractères) offre d'excellentes voix françaises avec nuances émotionnelles — idéal pour les livres audio et l'IA de personnages. Pour un TTS fonctionnel, OpenAI TTS ($15/1M) suffit largement.

Quelle API STT supporte le mieux le français ?+

OpenAI Whisper Large-v3 et Google STT offrent la meilleure précision en français. Whisper est plus économique ($0,006/min vs $0,024/min Google).
