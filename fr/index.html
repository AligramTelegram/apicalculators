Questions fréquentes

Tout sur le fonctionnement de ces calculatrices et l'origine des chiffres.

Quelle est la précision des calculs de coûts LLM ? +

Ils utilisent les tarifs API publics publiés pour 2026 d'OpenAI, Anthropic, Google et autres, révisés mensuellement. Ils n'incluent pas les remises entreprise, le cache de prompts ou les économies d'API par lots — considérez-les comme une estimation maximale pour la budgétisation.

APICalculators est-il gratuit ? +

Oui. Chaque calculatrice est gratuite, sans inscription ni paywall. Nous finançons le site via les publicités display et les partenariats d'affiliation.

Stockez-vous ou envoyez-vous mes données ? +

Non. Tous les calculs s'exécutent entièrement dans votre navigateur en JavaScript. Rien de ce que vous saisissez n'est transmis à un serveur ni conservé au-delà de votre session.

Quel processeur de paiement est le moins cher ? +

Cela dépend de votre valeur de transaction moyenne et de votre besoin de gestion fiscale. Stripe gagne souvent sur le pourcentage brut pour les transactions élevées ; Paddle et Lemon Squeezy intègrent la conformité TVA mondiale dans un taux plus élevé. La calculatrice montre la différence réelle en dollars.
