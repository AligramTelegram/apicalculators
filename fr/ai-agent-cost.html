Questions fréquentes

Quel est le coût d'un pipeline agent IA typique ?+

Pipeline budget (GPT-5.4 nano partout) : ~$0,50/100 exécutions. Pipeline qualité (Sonnet 4.6 travailleur) : ~$30–50/100 exécutions.

GPT-5.4 nano pour les agents IA — est-ce adapté ?+

Oui pour le planificateur et le réviseur. GPT-5.4 nano ($0,20/$1,25 par 1M) est 25× moins cher que GPT-5.5 et suffisant pour les tâches structurées.

Comment optimiser les coûts d'un agent IA ?+

Modèle bon marché pour planificateur/réviseur, modèle puissant seulement pour le travailleur. Cache pour les contextes répétés. Minimiser les tokens de sortie.
