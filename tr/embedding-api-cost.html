Sık Sorulan Sorular

Embedding token maliyeti nedir? +

OpenAI text-embedding-3-small $0.02/1M token. 500.000 belge (ortalama 200 token/belge) = 100M token = $2. Voyage voyage-3 ile aynı = $6. Indexleme genellikle tek seferlik yapılır.

OpenAI vs Cohere embedding karşılaştırması? +

OpenAI text-embedding-3-small ($0.02/1M) en ucuz yönetilen seçenektir. Cohere embed-v3 ($0.10/1M) çok dilli desteği ve bazen daha yüksek doğruluğuyla 5x pahalıdır. Türkçe içerik için Cohere değerlendirilebilir.

RAG için en ucuz embedding API hangisi? +

Yönetilen API'lar arasında OpenAI text-embedding-3-small ($0.02/1M) en ucuzdur. Self-hosted için Hetzner VPS üzerinde nomic-embed veya all-MiniLM sıfır API maliyetiyle çalışır.
